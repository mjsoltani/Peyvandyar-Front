# Peyvandyar Frontend

فرانت‌اند Next.js پنل پیوندیار.

## شروع کار

```bash
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را باز کنید.

## مستندات

همهٔ راهنماهای معماری، فیچر، API و استقرار در پوشهٔ **[docs/](./docs/README.md)** هستند.

## اسکریپت‌ها

تست‌های دستی API در [`scripts/`](./scripts) قرار دارند.
